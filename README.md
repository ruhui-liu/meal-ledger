# 饭账本

实验室聚餐轮流付款的记账网站：记录每一餐谁付的、几个人吃、怎么分，实时算出每个人该给谁多少。纯静态网页，挂在 GitHub Pages 上，手机和电脑都能用。

## 功能

- **记一笔**：日期、类型（早/午/晚餐…）、地点、币种（日元 / 人民币）、金额、谁付的、支付方式（现金 / 刷卡 / 支付宝 / 微信支付 / PayPay / 其他，可在设置里增删）、谁一起吃。
  - 分账方式：**平均分**、**指定金额**（没指定完的部分由所有人平均分，比如「我多点了 14300 円，剩下大家平分」）、**按比例**（比如用人民币刷卡、按各人点的日元菜价分）。
  - 金额可以直接写算式：`3200+2880`、`23580/3`。
  - 汇率自动按**消费当天的银联汇率**（日元→人民币），也可以手动改。
  - 来了新同学？在「谁付的钱」「谁一起吃」里点 **＋ 新成员** 就能直接添加（设置 → 成员 里也可以添加、改名、隐藏）。
- **账目**：按月份列出每一笔消费和还款，可按人、类型搜索筛选；点开看每个人分摊多少，可编辑 / 删除 / 复制为新账。
- **结算**：谁该给谁多少。
  - 分币种（日元、人民币分开，互不抵消）/ 全换成人民币 / 全换成日元（**每笔按自己消费日的汇率**换算后再汇总）。
  - 两两抵消（两人之间互相欠的先抵消）/ 最少转账（按每个人的净额重新配对，转账次数最少）。
  - 只看我；点一行看两人之间的全部往来明细；一键「还款」。
- **还款**：记录谁还了谁多少；可以付人民币来抵日元欠款（按还款日汇率换算）。
- **统计**：每个人付了多少、自己吃了多少、付款/参与次数，支付方式分布，常去的店；可选时间范围。
- **数据**：导出 JSON 备份、导出 CSV（Excel 可打开）、从 JSON 恢复。
- **外观**：设置 → 外观，可以选跟随系统、浅色或深色，每台设备分别记住。
- **界面风格**：默认 Google 简约风（Material 3），设置里还可以换成 iOS 原生、清爽薄荷绿、深色金融、活泼圆润、三星 One UI、暖橙（原版），每台设备分别记住；都支持系统深色模式。
- **中文 / English**：右上角的 EN / 中 按钮一键切换界面语言（设置里也可以选），每台设备分别记住。

## 更多功能

- **下次该谁付**：结算页顶部按人民币换算的净额，建议由欠得最多的人请客（设置 → 功能 里可以关掉）。
- **复制结算消息 / 提醒还钱**：一键生成文字，贴到微信、LINE 群里。
- **收款码**：每个人可以上传 PayPay / 微信支付 / 支付宝收款码，还款时直接显示。
- **小票照片**：记账时可附最多 4 张照片，存在仓库 `data/media/` 里。
- **识别小票**：拍完小票自动识别日期、店名、合计金额并填进表单（在手机上用 Tesseract.js 识别，照片不会发给第三方；第一次使用会下载约 3 MB 的识别模型）。
- **一键结清**：在两人明细里把日元、人民币欠款一次记成还款。
- **操作历史 / 撤销**：设置 → 数据 → 操作历史，任何一次修改都可以单独撤销。
- **重复记账提醒**：保存时发现同一天金额相近或同一家店的账，会先提醒可能已有人记过。
- **按店名带出上次设置**：选了去过的店，自动带出上次的参与人、币种、支付方式。
- **草稿**：记一笔记到一半离开，3 天内回来会自动恢复。
- **按菜分账**：每道菜选谁吃了，税 / 服务费 / 优惠按点菜金额比例分摊；识别小票可以自动列出菜单。
- **多个账本**：旅行、出差可以单独开账本（设置 → 账本），各自的账目、成员、结算互不影响。主账本是 `data/ledger.json`，其他账本在 `data/ledgers/`，列表在 `data/ledgers.json`。
- **分享预览卡片**：网址发到微信 / LINE 时显示带图标和简介的卡片。
- **统计图表**：近 12 个月花费、每个人付了 vs 自己吃了。
- **离线可用**：打开过一次后，没网也能打开；离线记的账联网后自动同步。

## 汇率（银联）

- [`data/rates.json`](data/rates.json) 存着每天的银联 JPY→CNY 汇率（`1円 = 多少元`，银联卡在日本刷日元时按这个价扣人民币），从 2026-05-01 开始。
- GitHub Actions（[`.github/workflows/update-rates.yml`](.github/workflows/update-rates.yml)）每 3 小时运行一次 [`scripts/update_rates.py`](scripts/update_rates.py)，从银联国际官网拉取新的一天并提交。也可以在仓库的 **Actions → 更新银联汇率 → Run workflow** 手动运行。
- 每笔账、每笔还款都按**自己日期**的银联汇率换算。如果当天的汇率还没发布（比如刚吃完饭就记账），会先暂用前一天的，等当天的汇率更新后自动换成当天的，不需要改账。
- 手动填写的汇率优先于银联汇率。
- 期初结转（Excel 导入的余额）统一按 2026-05-26 的银联汇率。

## 数据保存在哪

数据就是这个仓库里的 [`data/ledger.json`](data/ledger.json)。网页通过 GitHub API 读写它，**每次保存 = 一次 commit**，所以在 GitHub 上可以看到完整的修改历史，也可以随时回滚。

- **没有 Token**：打开网页可以查看所有账目和结算（只读）。
- **有 Token**：可以记账。Token 只保存在你自己的手机/电脑浏览器里，不会上传到任何地方。
- 两个人同时记账也没关系：保存时如果发现别人刚改过，会自动拉取最新数据再提交。
- 没网的时候记的账会先存在手机上（右上角显示「待同步」），有网后点一下就会同步。

## 部署（第一次）

1. 在 GitHub 新建仓库（例如 `meal-ledger`），把这个文件夹的所有文件推上去。
2. 仓库 **Settings → Pages**：Source 选 *Deploy from a branch*，Branch 选 `main`、`/ (root)`，保存。
3. 一两分钟后打开 `https://<你的用户名>.github.io/meal-ledger/`。
4. 创建 Token：GitHub 右上角头像 → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**
   - Repository access：*Only select repositories* → 选这个仓库
   - Permissions → Repository permissions → **Contents：Read and write**
   - 有效期可以选长一点（最长 1 年，过期后重新生成填进去即可）
5. 打开网页 → **设置 → GitHub 同步**，用户名和仓库名会自动识别，把 Token 粘贴进去 → 「保存并连接」。
6. （可选）仓库 **Actions** 页面确认「更新银联汇率」已启用。

> 想让其他同学也能记账：在仓库 Settings → Collaborators 里把他们加进来，他们各自生成自己的 Token 填进去即可。只想让他们看的话，直接把网址发给他们就行。

## 放到手机桌面

- iPhone：用 Safari 打开网址 → 分享 → **添加到主屏幕**。
- Android：Chrome 打开 → 菜单 → **添加到主屏幕 / 安装应用**。

之后就像一个 App 一样打开。

## 数据格式（`data/ledger.json`）

```jsonc
{
  "members":  [{ "id": "rh", "name": "Ruhui", "short": "RH" }],
  "methods":  ["现金", "刷卡", "支付宝", "微信支付", "PayPay", "其他"],
  "bills": [{
    "id": "b_…", "kind": "meal",          // "carry" = 期初结转（从 Excel 导入的余额）
    "date": "2026-05-29", "meal": "晚餐", "title": "一风堂",
    "currency": "JPY", "amount": 6080, "payer": "zq", "method": "PayPay",
    "split": { "mode": "amount", "members": ["rh","rq","zq","b"], "values": { "rh": 1090, "rq": 1620, "zq": 1880, "b": 1490 } },
    // 汇率不存在账目里，按 date 查 data/rates.json；只有手动改过才会有：
    // "rate": 0.0427, "rateSource": "manual",
    "note": "", "createdBy": "rh", "createdAt": "…"
  }],
  "payments": [{
    "id": "p_…", "date": "2026-06-12", "from": "t", "to": "rh",
    "currency": "CNY", "amount": 1000, "method": "微信支付",
    "creditCurrency": "JPY"   // 可选：换算成日元抵扣日元欠款（按还款日汇率）
  }]
}
```

## 更新网站代码

新加深色样式时照常写 `@media (prefers-color-scheme: dark) { … }`，然后运行 `python3 scripts/scheme_css.py css/style.css css/themes.css`，它会自动改写成支持「跟随系统 / 浅色 / 深色」手动切换的形式。

改了 `js/` 或 `css/` 之后运行 `python3 scripts/bump_version.py` 再提交，这样手机浏览器会立刻加载新版本，而不是用缓存里的旧代码。

## 本地预览

```bash
python3 -m http.server 8000
```

然后打开 <http://localhost:8000>。不在 github.io 上运行时是「本地模式」：数据只存在浏览器里，不会改动仓库。
